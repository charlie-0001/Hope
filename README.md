# About
Hope is a Roblox game created by charlie-0001 on GitHub and beecolonthree on Roblox. This is a solo project with very minimal use of AI. It is an extremely difficult 3D platformer featuring a variety of platforming mechanics like falling platforms, kill bricks, music zones, lighting changers, spinning platforms, etc. Additionally, for any onlookers curious about the progress of this codebase, I will try be pushing out my progress at least once per week, which you can check in the commit history.

# Goal
The goal of this project is to improve my programming skills while doing something I love, game development. I hope for this project to serve as an outlet of self expression and something I can look back on proudly when it's done. Additionally, I want this codebase to be something I can use and add to long term for future Roblox related projects.
